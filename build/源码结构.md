# SR_UCH 源码结构约定与现状（2026-10-31）

> 目的：让"文件放哪儿、怎么拆、拆完要改什么"有唯一答案，避免再出现巨兽文件与半拆状态。

## 1. 三个程序集

| 程序集 | 位置 | 说明 |
|---|---|---|
| `SR_UCH.dll` | `SR_UCH/MainPlugin.cs` + `SR_UCH/SR_UCH/*.cs` + `SR_UCH/Features/*.cs` | BepInEx 插件（核心 + 内置功能），合并模式一个 DLL |
| `SR_UCH_EX.dll` | `SR_UCH_EX/ExModule/*.cs` | 独立程序集，由核心反射/`ITweak` 拉起，**只允许**用 `SRApi` 契约 |
| 语言包 / 外部功能 | 用户 DLL | 实现 `ILanguagePack` / `ITweak` |

## 2. 核心分片（`SR_UCH/SR_UCH/`）

统一都是 `public partial class SR`（`SR.Contracts.cs` 之外），按职责分片：

| 文件 | 职责 |
|---|---|
| `SR.Contracts.cs` | 契约层：`SRApi` / `SRApi.Ctl` / `SRApi.Table` / `SRApi.Ref` / `SRContract` / `SrTimeouts` / `Slots` / `MainThread`。**可独立编译**（`-Separate` 模式） |
| `SR.Core.cs` | 生命周期、注入 sink、配置存放、启动自检 |
| `SR.Window.cs` | 窗口与页面骨架（滚动区、底栏、页签、页面钩子） |
| `SR.Settings.cs` | 设置行渲染（`RenderEntryRow` / 各类控件 / 紧凑行） |
| `SR.Ctl.cs` | 控件与皮肤门面（样式、复选框、按钮、操作列、滚动条） |
| `SR.Table.cs` | 表格几何与交互（11 阶段绘制、列拖动、行命中、滚动条） |
| `SR.Settings`→`SR.ConfigMigration.cs` | cfg 段名/键名迁移 |
| `SR.Localization.cs` | 本地化表、悬浮条目组装（`ComposeTip`）、默认值/按键行 |
| `SR.ColorPicker.cs` | 调色板 |
| `SR.Ext.cs` | 扩展点注册表 |

## 3. 功能分片（`SR_UCH/Features/`）

一个功能一个主文件，按需加 `功能名.职责.cs` 分片（同一 `partial class`）：

```
BuildingPresets.cs        列表/表格/列/单元格/动作按钮
BuildingPresets.Load.cs   加载流程（含 ReloadGuard）
BuildingPresets.Io.cs     导入导出 / 索引 / 快照获取
BuildingPresets.Mods.cs   24 项修改器的编码、读 XML、悬浮预览
BuildingPresets.Util.cs   XML/时间/JSON 辅助
HUD.cs                    配置 + 注册 + 设置页
HUD.State.cs              每帧状态更新（相位/计时/回合/关卡）
Online.cs                 联机主流程      Online.Join.cs / Online.Table.cs / Online.LobbyList.cs / Online.Watchdog.cs
Level.cs                  Level.*  关卡重载 / 工具 / 快照 / 派对盒
Experiments.cs            Experiments.*  实验项（Bounds / Misc / Scene）
```

## 5. 拆分/搬移文件的固定步骤

1. 只做"剪贴"：不改逻辑、不改可见文案
2. 新文件头：`using` 与原文件一致 + `namespace` + `public partial class 原名 {`
3. 同步**两处** rsp：
   - `_tools/rsp/sr_uch.rsp`（绝对路径，真实编译清单）
   - `SR_UCH/build/rsp/sr_uch.rsp`（相对路径，文本守卫按它比对磁盘）
   - 若属某功能的 `feat_*.rsp`，也要加（结构：nologo/target/out/refs + 源文件）
4. 若是新建功能文件，还要更新 `SR_UCH/SR_UCH.csproj` 的 `<Compile Include>`（`-Check` 的 csproj 守卫会校验两条链引用一致）
5. 拆分后下调 `build/file-size.txt` 里该文件的登记值

## 6. 守卫（`build/guards-text.ps1`，13 项）

`API 白名单` / `契约边界` / `功能层不碰实现层` / `rsp 覆盖` / `编码` / `悬浮条目 3 行` / `cs 编码(LF+无BOM)` / `裸 catch` / `缩进` / `分区字段` / `静默 catch 棘轮` / `悬浮组装统一` / **`单文件行数`**

- 单文件上限 **900 行**；超限文件必须登记在 `build/file-size.txt`，数字只允许变小
- 当前登记 7 个：`SR.Contracts 1334 / SR.Settings 1243 / SR.Core 1178 / SR.Ctl 1117 / BuildingPresets 1092 / HUD 1015 / ExModule.Core 912`
