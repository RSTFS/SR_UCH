# SR_UCH

[English](README.md) | **简体中文**

> 《Ultimate Chicken Horse》游戏内增强模组 · A quality-of-life mod suite for **Ultimate Chicken Horse**（BepInEx 5 / Harmony）

一个装上就能用的游戏内设置面板：把关卡、建造、聊天、联机、实验类功能都收进一个可排序的侧栏，
不用改游戏文件、不用进 BepInEx 配置文件翻选项。界面语言可随时切换，切换后立即生效。

**中文 / English**：游戏内设置页随时切换，切换即刻生效。

---

## 安装 Install

1. 装好 **BepInEx 5.4**（第一次装需要先跑一次游戏让它生成加载器）。
2. 把 `SR_UCH.dll` 放进 `Ultimate Chicken Horse\BepInEx\plugins\`。

首次启动会生成配置文件 `BepInEx\config\SR_UCH_data.cfg`

## 快速开始 Quick Start

| | |
|---|---|
| 打开面板 | **`Insert`**（可在设置页改键） |
| 总开关 | **All Enabled** 默认**关**，打开后各功能才生效 |
| 界面语言 | 默认英文，可在设置页切中文 |
| 改按键 | 面板里点按键框：`Esc` 清空，`Shift+Esc` 取消 |

**设置**页现在是**单页**，不再分页；**自检**与**通知**入口移到了**底栏**（设置 | 通知 | 自检）。
（页签栏与「恢复默认」按钮均已删除。）

**自检**页是卡片式体检报告：一张结论卡（含**重新扫描**、**复制报告**、**写入日志**）；
一张「目标与配置」卡 —— 按名绑定的补丁目标/反射成员失效时会变琥珀色并列出具体条目；
一张「第三方插件」卡列出从 `BepInEx\plugins` 加载的其它插件，并标注已知冲突/注意事项；
一张「按键中心」卡汇总所有自动快捷键与手动键位（可一键清除、重复组合带 ⚠）；
一张「主动自检」卡可主动验证 API 注入/补丁/槽位/通知/配置/按键并**导出支持包**（单个 txt：诊断报告 + 日志尾部 + 插件清单，路径自动复制）；
一张「最近异常」卡显示最近 16 条 Guard 记录；
一张「帧钩子」卡显示各钩子耗时。游戏更新导致部分功能失效时，这里是首先该看的地方。
帧钩子剖析默认关闭（开关就在该卡片里），避免一直往日志里写性能记录。

## 功能 Features

面板左侧是栏目，右侧是页面。下面按栏目列。

### 建造 build

- **无视碰撞** —— 方块可以放在任意位置：重叠、悬空、交叉都可以。快捷键 `F1` 开关。
- **自由放置** —— 关掉 1 单位网格吸附，摆放可以微调。快捷键 `F2` 开关。
- **解除建造上限** —— 树屋里保存 / 发布的"满度"上限（默认 500）可以自己定。

### 关卡 Level（两页：派对盒 | 关卡工具）

- **重载关卡** —— 真正重载当前场景，**已放好的方块全部保留**；分数可选择保留或重置。
- **广播方块快照** —— 房主把自己看到的方块重发给全场，全员就地重建（修不同步，不用重载关卡）。
- **放弃道具** —— 排队模式里手上拿着道具又不想放了，按键丢掉。走游戏自己的通道，**全员可见**。
- **派对盒炸弹** —— 所有人发一句「炸弹！」快捷消息，就在派对盒里生成炸弹。

### 联机 Online

- **联机房间列表** —— 按区域、模式、进度、满员等条件筛选，排序、刷新、加入。
- **版本/功能握手**：联机时每 20 秒互发一次 SR 功能签名（走游戏已有的带外消息，不改任何游戏状态）；**双方都装**了 mod 且功能表/契约版本不一致时弹一条提示。对方完全没装 mod 时不发签名，这种情况不提示。

### 混乱牌组 Chaos Deck

把本来「一整局固定」的对局规则，改成每回合抽一张牌。第 3 回合突然全员低重力、第 5 回合镜像操作 —— 一局自己长出新剧本。

**2.0 起只需房主安装。** 抽牌发的是**真实的游戏规则消息**（`MsgGameRuleSet` + 真实 `TabletRule` / `Value`），由游戏自己的 `TabletRulesScreen` 在非房主端写进 `Modifiers`，所以没装 mod 的房客也会一起变，并能在原生规则界面看到当回合改了什么。房主端被游戏的 `!IsHost` 守卫挡住，因此本地双写一次。

- **房主单一随机源**：只有房主（或离线本机）抽牌，广播的是「抽到的结果」而不是种子，房客完全不随机，天然不会不同步。
- **17 张牌**：低重力 / 高重力 / 超重 / 弱跳跃 / 高跳跃 / 慢冲刺 / 快冲刺 / 龟速冲刺 / 慢平台 / 快平台 / 停滞平台 / 禁用墙跳 / 镜像操作 / 跳舞无敌 / 玩家互撞 / 无摩擦 / 慢射速，每张都能在牌池里单独关掉；牌池页按「数值规则 / 布尔规则」分组（**无搜索框**）。游戏速度、体型、相机翻转、末日仍不收录（碰全局 `Time.timeScale`、相机或需重建绘制对象）。**慢射速牌收录，但有一处已知不对称**：游戏 `OnModifiersDynamicChange()` 只在房客端触发（房主被 `!IsHost` 挡住），它会顺带刷新 `Time.timeScale`；若两端 timeScale 因暂停菜单/其它 mod 不同，房客会被拉回 `GameSpeed`、房主不会。只影响这一张牌，介意可从牌池关掉。
- **可调项**：每几回合抽一次、最多同时生效几张、抽牌提示、手动重抽快捷键；页面把当前牌面画成**卡片**（牌名 + 效果 + 绿边增益 / 红边减益 / 蓝边中性）。
- **随时可退回**：开局快照原规则值；关闭开关 / 对局结束时既重发每条规则的树屋原值（让未装 mod 的房客还原），也本地还原房主那份，并通知装了 mod 的房客清掉牌面标记。
- **房内 mod 清单**：复用同一条规则消息做周期握手，面板显示房间里哪些玩家装了本 mod。客户端收到的所有消息都来自服务器连接，因此握手用「本机玩家号」而不是 `conn.connectionId` 区分发件人。
- 只用游戏已有的规则与消息类型：**不新增 Harmony 补丁、不新增 msgType、不新增反射登记、不改相机、不生成实体、不加线程**。

### 品质光芒 Rarity Glow

按**当前概率**给派对盒里的道具加一层柔光：概率越低越稀有、光越亮。分档按**本盒内相对稀有度**（对数插值），不再用固定阈值，避免整盒只有一个颜色。

- 概率口径与派对盒自己的抽取逻辑同源：`BlockGroup.GetItemFilterWeight`（自动处理 `FilterOverride`），退化路径走 `GameSettings.GetBlockFrequency` + `TabletBlockList.GetWeightFromStepValue`。**不是**道具的基础稀有度。
- 6 档品质：泛滥 / 普通 / 精良 / 稀有 / 史诗 / 传说，**每档颜色可自定义**（十六进制，设置页六行）；权重为 0（本局不会出现）的道具不发光。强度、尺寸、呼吸脉动均可调。
- 实现方式：光晕是**道具自己的子对象**（程序生成径向渐变贴图，整局只建一次），排在道具本体后面、同排序层、同为 UI layer 5。用 `Transform.Find` 判重与更新，**完全无状态**——道具消失时光晕自动带走，不建强引用字典。
- 纯本地视觉：概率本来就是同步的，各端各算各画；不碰网络、不改原材质 / SpriteRenderer、不影响抽取结果、不新增补丁 / 反射 / 线程。
- 六档各用一份加色材质（避免共享材质把颜色压成一种）；光斑按档位放大到包围盒的 1.6–2.2 倍，像是从道具里散出来的光。

### 视觉辅助 Visual Aid

淡化 / 隐藏**其他玩家**，方便录屏、截图或看清自己的操作；纯本地画面，不改变玩法、不同步、不影响联机。

- 透明度可调（0 = 完全隐藏，100 = 保持原样）；可选「只在近距离淡化」并设置距离（1-30 米），对局内用快捷键临时开关（默认 F6，可改绑）。
- 只处理其他玩家：自己、未入座角色、菜单 / 树屋阶段一律不动。实现是 `Character.Update` 与 `CharacterOpacityController.Update` 两个 Postfix，每帧写 alpha / currentOpacity。
- 检测到 **CamHog**（同思路的现成 mod）已加载时自动让位并在页面提示——两个 mod 同时写透明度会互相覆盖，不如让一个说了算。
- 只用游戏自己的 public 成员（`Character.SpriteRenderer` / `HasJetpack` / `NameTag.maxOpacity` / `Character.AllCharacters` / `Util_SpriteRenderer.SetAlpha`），零反射、不碰网络。

### 通知 Notification Hub

把散落在各处的**屏幕提示统一收口**。`Notify`、`NotifyT`、`NotifyTag` 与核心自己的提示全都汇到 `SR.Notify.cs` 的 `NotifyImpl`，所以只在核心留一个可选钩子就能覆盖全部来源，不用改任何调用点；没装这个功能时行为一字不变。

- **优先级分级**：要动手的（失败、拒绝、被拦下）> 一般反馈 > 纯确认；3 秒窗口内同来源同内容合并成一条（卡片只显示正文，不再显示 `×N`）；`NotifyEx` 可显式指定级别。
- **单一开关**：关掉通知中心就把全部提示交回游戏原生显示；不再有「原生提示 / 局内浮层 / 对局中静默」三个开关。
- **动作按钮**：`NotifyEx` 可带一个动作（如「撤销」），点击执行动作并关闭该条。
- **连发不吞**：**同时显示条数**只决定一次画几张，多出来的消息排队（最多 16 条）等前一条退场后依次滑入；每条只在真正上屏后才开始计停留时间，所以排队再久也不会「还没看到就过期」。
- 局内浮层自建常驻 `MonoBehaviour.OnGUI`：优先级色条 + 长度编码 + 逐渐缩短的剩余时间条；高优先级额外加同色描边。
- **过渡动效**：卡片从停靠侧淡入 + 滑入；插入/移除时整列卡片平滑让位（不是瞬移）；退场先淡出 + 滑出再从列表移除。
- **可调外观**：卡片宽度（100-500，默认 300）、浮层缩放（100-300，默认 200）、文字大小（10-32，默认 20）、卡片不透明度（20-100%，默认 64）、停靠位置（默认右下）、最多同时几条（1-6）、停留秒数（0.5-5，默认 1.5，步进 0.5）。动画固定内置（无开关）。
- **悬停暂停 / 点击关闭**：鼠标停在浮层上时暂停倒计时（剩余时间条同步冻结，看长提示不会被吞）；左键点卡片立即开始退场。

### 玩家轨迹 Player Tracker

- **移动轨迹**：在画面上绘制其他玩家最近的移动路径。
- 可调：轨迹长度、采样间隔、起点/终点线宽、瞬移判定距离、透明度。
- **默认关闭**；仅显示，不影响游戏判定。

### 方块破坏 Destroy Blocks

- 按 `Alt` 进入删除模式，滚轮切换目标，`Backspace` 删除。
- 删除时会显示**是谁放的**这个方块，可以追踪某个玩家。
- 另有列表模式：直接列出场上所有方块，刷新后点选。
- **破坏动画**开关会真正传给游戏的 `DestroySelf(..., useSmoke, ...)`：关掉后方块直接消失、不播烟雾。

### 会话 Chat

**对话窗口**页

- 按住 `Z` 显示聊天窗口，或按一下切成常驻（可改键）。
- 窗口缩放 `X` + 滚轮，文字大小 `C` + 滚轮。
- 可以关掉自动弹出、关掉淡入淡出、开启清晰度、调整窗口位置。
- 把「启用增强」关掉，游戏原本的字号 / 缩放 / 位置会**还原一次**后完全交回原版。

**对话内容**页

- 会话内的聊天记录面板，可以记录和发送。
- **发送走的是游戏自己的聊天通道**（`ChatSystem`，与游戏内聊天一致，房主/房客都能看到），不是本地只读。
- 记录、过滤、隐藏游戏聊天窗口、显示时间这些**只影响本机显示**，不会改动别人看到的内容。

### 快速调整 Quick Adjust

- **分数折扣** —— 把自己的 handicap 设成 100 减折扣，这一局立刻生效，平衡板上能看到；可一键恢复原值。
- **快速切换** —— 长按 `B` 在行动 ↔ 建造之间来回切。
- **挑战**（第 2 页）—— 死后自动重试 / 长按快速重试 + 等待秒数；挑战模式里死了自动重来。

### 角色 Character

- **自动选择** —— 进入树屋/房间时自动挑一次角色：指定角色 / 随机空闲 / 智能（按存档统计挑最常用的）；只处理已解锁的角色，已有角色不动。
- **自动时装** —— 角色选定后自动随机穿一套外观（只用已解锁的外观），也可以手动「随机整套」。

### 重生 Respawn（在「快速调整 → 重生」页）

- **重生延迟** —— 死亡后等多少秒再自动重生（挑战 / 自由通用，默认 0.5 秒，游戏原生长按阈值）。
- **出生无敌** —— 每次出生后的无敌秒数（默认 1 秒，游戏原生重生后就是 1 秒）。
- **炮弹卡死重生** —— 死了还卡在炮弹里超过 1.5 秒自动重生。
- **死亡无计分板** —— 挑战模式死亡时不弹记分板（只在死亡且尚未通关时生效）。

### 布局预设 Layout Presets

- 把当前方块布局保存为命名预设，之后一键加载（加载仅房主可用）。
- 预设存放在 `BepInEx/config/SR_UCH/presets/`；支持导出到剪贴板 / 从剪贴板导入，方便分享。
- 加载会走原生重载：分数是否保留取决于“重载关卡”的模式设置。

### HUD

- 屏幕小窗显示当前阶段、阶段倒计时与回合进度。
- 倒计时最后 10 秒变黄、最后 5 秒变红；可选闪烁与阶段切换提示。
- 纯本地：不发送任何网络消息，不影响游戏判定。可拖动；**拖动后的位置只在本次会话有效，不写配置**（下次启动回到默认位置）。
- 显示方式默认 **切换**：开局 HUD 就在，按键只负责隐藏/显示。
- 配置段原名「Round HUD」，升级后会自动迁移到 `[HUD]`，所有取值保留。

### 实验 Experiments

**关卡边界**页

- **解除关卡边界** —— 走出原关卡边界。每边外扩多少可调；「硬解除」能让光标和相机走得更远，

- **解除 UI3 覆盖** —— 去掉关卡里那块挡住画面的黑幕。**与「解除关卡边界」同一个开关**，不单独提供选项。

**场景**页

- 跳过加载动画、温柔加载（延后加载以避开卡顿）。
- **立即开始** —— 在树屋里直接开始关卡（需要至少有一扇门被选中）。

**其它**页

- **自由相机** —— 滚轮缩放视野，视野大小与相机移动速度均可调。
- **相机跟随** —— 相机移动速度可调。
- **跨平台联机** —— 直接改游戏自己的跨平台匹配开关（同时写回存档，重启后仍生效）。

## 可靠性 Reliability

**2026-10 静态审计**（286 条发现）已分级处理：**59 条 P0 全部落地**，每条都记录在
[`build/audit-p0-ledger.md`](build/audit-p0-ledger.md)，含状态（`ported` / `already-fixed` / `n-a`）、
依据与提交号。要点：

- 游戏更新后消失的补丁/反射目标会如实报成**失效**，不再"假健康"；契约层在日志通道注入之前
  写下的日志会先进缓冲、注入后补发，不再静默丢弃。
- 配置迁移不会把刚刚搬走的旧键清空；每一条被删除的键都会在启动日志里汇总一次。
- 设置页「恢复默认」不再挪动/缩放窗口，也不重置侧栏宽度。
- 原本挂在场景对象上的长任务（预设重载协程、加入流程）改挂常驻宿主；残留的
  `levelPortalXml` 与重载锁由注册的帧钩子兜底清理。

## 构建 Build

```powershell
# 需要：.NET SDK（提供 Roslyn csc）+ 本地游戏本体（提供引用程序集）
.\build\build.ps1                                        # -> bin\Release\SR_UCH.dll
.\build\build.ps1 -Deploy                                # 编译并复制到 <游戏>\BepInEx\plugins
.\build\build.ps1 -GameDir "D:\...\Ultimate Chicken Horse"
```

游戏目录会从常见 Steam 路径自动探测，也可用环境变量 `UCH_DIR` 指定。

```powershell
                                 # 编码、悬浮条目形状、静默 catch 与文件行数棘轮）
```

CI（`.github/workflows/guards.yml`）跑两个 job：`text-guards` 与 `unit-tests`，
破坏契约层或任一棘轮的 PR 会在评审前就变红。

裁剪构建（只把指定功能编进 DLL，选项不写进仓库清单）：

```powershell
.\build\build.ps1 -Features "HUD,Chat"            # 合并版 Lite
.\build\build.ps1 -Split -Features "HUD,Chat"    # 拆分版 Lite
```

```powershell
.\build\build.ps1 -All -Check            # 机械守卫：含构建与自检基线
```
