# SR_UCH

[English](README.md) | **简体中文**

> 《Ultimate Chicken Horse》游戏内增强模组 · A quality-of-life mod suite for **Ultimate Chicken Horse**（BepInEx 5 / Harmony）

一个装上就能用的游戏内设置面板：把关卡、建造、聊天、联机、实验类功能都收进一个可搜索的侧栏，
不用改游戏文件、不用进 BepInEx 配置文件翻选项。界面语言可随时切换，切换后立即生效。

**中文 / English**：游戏内设置页随时切换，切换即刻生效。

---

## 安装 Install

1. 装好 **BepInEx 5.4**（第一次装需要先跑一次游戏让它生成加载器）。
2. 把 `SR_UCH.dll` 放进 `Ultimate Chicken Horse\BepInEx\plugins\`。

首次启动会生成配置文件 `BepInEx\config\SR_UCH_data.cfg`

---

## 快速开始 Quick Start

| | |
|---|---|
| 打开面板 | **`Insert`**（可在设置页改键） |
| 总开关 | **All Enabled** 默认**关**，打开后各功能才生效 |
| 界面语言 | 默认英文，可在设置页切中文 |
| 改按键 | 面板里点按键框：`Esc` 清空，`Shift+Esc` 取消 |

**设置**页现在是两个页签（**通用** / **自检**），页签常驻页顶、`Ctrl` + 滚轮切换；
「恢复默认」在页签栏最右侧（它**不会**动窗口大小/位置与侧栏宽度）。

**自检**页是卡片式体检报告：一张结论卡（含**重新扫描**、**复制报告**、**写入日志**）；
一张「目标与配置」卡 —— 按名绑定的补丁目标/反射成员失效时会变琥珀色并列出具体条目；
一张「帧钩子」卡显示各钩子耗时。游戏更新导致部分功能失效时，这里是首先该看的地方。
帧钩子剖析默认关闭（开关就在该卡片里），避免一直往日志里写性能记录。

## 功能 Features

面板左侧是栏目，右侧是页面。下面按栏目列。

### 建造 build

- **无视碰撞** —— 方块可以放在任意位置：重叠、悬空、交叉都可以。快捷键 `F1` 开关。
- **自由放置** —— 关掉 1 单位网格吸附，摆放可以微调。快捷键 `F2` 开关。
- **解除建造上限** —— 树屋里保存 / 发布的"满度"上限（默认 500）可以自己定。

### 关卡 Level（两页：派对盒 | 关卡工具）

- **重载关卡** —— 真正重载当前场景，**已放好的方块全部保留**；分数可选择保留或重置。
- **广播方块快照** —— 房主把自己看到的方块重发给全场，全员就地重建（修不同步，不用重载关卡）。
- **放弃道具** —— 排队模式里手上拿着道具又不想放了，按键丢掉。走游戏自己的通道，**全员可见**。
- **派对盒炸弹** —— 所有人发一句「炸弹！」快捷消息，就在派对盒里生成炸弹。

### 联机 Online

- **联机房间列表** —— 按区域、模式、进度、满员等条件筛选，排序、刷新、加入。

### 玩家轨迹 Player Tracker

- **移动轨迹**：在画面上绘制其他玩家最近的移动路径。
- 可调：轨迹长度、采样间隔、起点/终点线宽、瞬移判定距离、透明度。
- **默认关闭**；仅显示，不影响游戏判定。

### 方块破坏 Destroy Blocks

- 按 `Alt` 进入删除模式，滚轮切换目标，`Backspace` 删除。
- 删除时会显示**是谁放的**这个方块，可以追踪某个玩家。
- 另有列表模式：直接列出场上所有方块，刷新后点选。
- **破坏动画**开关会真正传给游戏的 `DestroySelf(..., useSmoke, ...)`：关掉后方块直接消失、不播烟雾。
- 可以选择允许客户端也能删（需要对应扩展模块支持）。

### 会话 Chat

**对话窗口**页

- 按住 `Z` 显示聊天窗口，或按一下切成常驻（可改键）。
- 窗口缩放 `X` + 滚轮，文字大小 `C` + 滚轮。
- 可以关掉自动弹出、关掉淡入淡出、开启清晰度、调整窗口位置。
- 把「启用增强」关掉，游戏原本的字号 / 缩放 / 位置会**还原一次**后完全交回原版。

**对话内容**页

- 会话内的聊天记录面板，可以记录和发送。
- **发送走的是游戏自己的聊天通道**（`ChatSystem`，与游戏内聊天一致，房主/房客都能看到），不是本地只读。
- 记录、过滤、隐藏游戏聊天窗口、显示时间这些**只影响本机显示**，不会改动别人看到的内容。

### 快速调整 Quick Adjust

- **分数折扣** —— 把自己的 handicap 设成 100 减折扣，这一局立刻生效，平衡板上能看到；可一键恢复原值。
- **快速切换** —— 长按 `B` 在行动 ↔ 建造之间来回切。
- **死后自动重试** / **快速重试** —— 挑战模式里死了自动重来。

### 布局预设 Layout Presets

- 把当前方块布局保存为命名预设，之后一键加载（加载仅房主可用）。
- 预设存放在 `BepInEx/config/SR_UCH/presets/`；支持导出到剪贴板 / 从剪贴板导入，方便分享。
- 加载会走原生重载：分数是否保留取决于“重载关卡”的模式设置。

### HUD

- 屏幕小窗显示当前阶段、阶段倒计时与回合进度。
- 倒计时最后 10 秒变黄、最后 5 秒变红；可选闪烁与阶段切换提示。
- 纯本地：不发送任何网络消息，不影响游戏判定。可拖动；**拖动后的位置只在本次会话有效，不写配置**（下次启动回到默认位置）。
- 显示方式默认 **切换**：开局 HUD 就在，按键只负责隐藏/显示。
- 配置段原名「Round HUD」，升级后会自动迁移到 `[HUD]`，所有取值保留。

### 实验 Experiments

**关卡边界**页

- **解除关卡边界** —— 走出原关卡边界。每边外扩多少可调；「硬解除」能让光标和相机走得更远，
  半径可调；方块的越界放置会一并打开。
- **解除 UI3 覆盖** —— 去掉关卡里那块挡住画面的黑幕。**与「解除关卡边界」同一个开关**，不单独提供选项。

**场景**页

- 跳过加载动画、温柔加载（延后加载以避开卡顿）。
- **立即开始** —— 在树屋里直接开始关卡（需要至少有一扇门被选中）。

**其它**页

- **自由相机** —— 滚轮缩放视野，视野大小与相机移动速度均可调。
- **相机跟随** —— 相机移动速度可调。
- **跨平台联机** —— 直接改游戏自己的跨平台匹配开关（同时写回存档，重启后仍生效）。

## 可靠性 Reliability

**2026-10 静态审计**（286 条发现）已分级处理：**59 条 P0 全部落地**，每条都记录在
[`build/audit-p0-ledger.md`](build/audit-p0-ledger.md)，含状态（`ported` / `already-fixed` / `n-a`）、
依据与提交号。要点：

- 游戏更新后消失的补丁/反射目标会如实报成**失效**，不再"假健康"；契约层在日志通道注入之前
  写下的日志会先进缓冲、注入后补发，不再静默丢弃。
- 配置迁移不会把刚刚搬走的旧键清空；每一条被删除的键都会在启动日志里汇总一次。
- 设置页「恢复默认」不再挪动/缩放窗口，也不重置侧栏宽度。
- 原本挂在场景对象上的长任务（预设重载协程、加入流程）改挂常驻宿主；残留的
  `levelPortalXml` 与重载锁由注册的帧钩子兜底清理。

下面的文本守卫与单元测试会拦住同形态的新回归。

## 构建 Build

```powershell
# 需要：.NET SDK（提供 Roslyn csc）+ 本地游戏本体（提供引用程序集）
.\build\build.ps1                                        # -> bin\Release\SR_UCH.dll
.\build\build.ps1 -Deploy                                # 编译并复制到 <游戏>\BepInEx\plugins
.\build\build.ps1 -GameDir "D:\...\Ultimate Chicken Horse"
```

游戏目录会从常见 Steam 路径自动探测，也可用环境变量 `UCH_DIR` 指定。

### 测试与守卫 Tests and guards

以下检查**不需要安装游戏**（契约层用本地 `tests/UnityStubs.cs` + `tests/BepInExStubs.cs` 编译），
新克隆的仓库与 CI 都能跑：

```powershell
.\build\run-tests.ps1 -NoGame    # 契约层必须编译通过 + 13 条断言（dotnet, net8.0）
.\build\run-tests.ps1            # 有游戏时同样的测试走 csc + 真实 BepInEx
.\build\guards-text.ps1          # 13 项文本守卫（API 白名单、层边界、rsp 覆盖、
                                 # 编码、悬浮条目形状、静默 catch 与文件行数棘轮）
```

CI（`.github/workflows/guards.yml`）跑两个 job：`text-guards` 与 `unit-tests`，
破坏契约层或任一棘轮的 PR 会在评审前就变红。

更重的检查（完整 rsp 构建、拆分构建、csproj 构建、运行时自检比对）需要游戏引用程序集，只在本地跑：

```powershell
.\_tools\build_sr_uch.ps1 -All -Check     # 机械守卫：含构建与自检基线
.\build\check-selftest.ps1                # 把日志里的 [SR.SelfTest] 行与基线比对
```
