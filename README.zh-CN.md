# SR_UCH

[English](README.md) | **简体中文**

> 《Ultimate Chicken Horse》游戏内增强模组 · A quality-of-life mod suite for **Ultimate Chicken Horse**（BepInEx 5 / Harmony）

一个装上就能用的游戏内设置面板：把关卡、建造、聊天、联机、实验类功能都收进一个可排序的侧栏，
不用改游戏文件、不用进 BepInEx 配置文件翻选项。界面语言可随时切换，切换后立即生效。

**中文 / English**：游戏内设置页随时切换，切换即刻生效。

---

## 安装 Install

1. 装好 **BepInEx 5.4**（第一次装需要先跑一次游戏让它生成加载器）。
2. 把 `SR_UCH.dll` 放进 `Ultimate Chicken Horse\BepInEx\plugins\`。

首次启动会生成配置文件 `BepInEx\config\SR_UCH_data.cfg`

---

## 快速开始 Quick Start

| | |
|---|---|
| 打开面板 | **`Insert`**（可在设置页改键） |
| 总开关 | **All Enabled** 默认**关**，打开后各功能才生效 |
| 界面语言 | 默认英文，可在设置页切中文 |
| 改按键 | 面板里点按键框：`Esc` 清空，`Shift+Esc` 取消 |

**设置**页现在是两个页签（**通用** / **自检**），页签常驻页顶、`Ctrl` + 滚轮切换；
「恢复默认」在页签栏最右侧（它**不会**动窗口大小/位置与侧栏宽度）。

**自检**页是卡片式体检报告：一张结论卡（含**重新扫描**、**复制报告**、**写入日志**）；
一张「目标与配置」卡 —— 按名绑定的补丁目标/反射成员失效时会变琥珀色并列出具体条目；
一张「帧钩子」卡显示各钩子耗时。游戏更新导致部分功能失效时，这里是首先该看的地方。
帧钩子剖析默认关闭（开关就在该卡片里），避免一直往日志里写性能记录。

## 功能 Features

面板左侧是栏目，右侧是页面。下面按栏目列。

### 建造 build

- **无视碰撞** —— 方块可以放在任意位置：重叠、悬空、交叉都可以。快捷键 `F1` 开关。
- **自由放置** —— 关掉 1 单位网格吸附，摆放可以微调。快捷键 `F2` 开关。
- **解除建造上限** —— 树屋里保存 / 发布的"满度"上限（默认 500）可以自己定。

### 关卡 Level（两页：派对盒 | 关卡工具）

- **重载关卡** —— 真正重载当前场景，**已放好的方块全部保留**；分数可选择保留或重置。
- **广播方块快照** —— 房主把自己看到的方块重发给全场，全员就地重建（修不同步，不用重载关卡）。
- **放弃道具** —— 排队模式里手上拿着道具又不想放了，按键丢掉。走游戏自己的通道，**全员可见**。
- **派对盒炸弹** —— 所有人发一句「炸弹！」快捷消息，就在派对盒里生成炸弹。

### 联机 Online

- **联机房间列表** —— 按区域、模式、进度、满员等条件筛选，排序、刷新、加入。

### 时间控制 Time Control

- **梦境** —— *本地*定格：把 `Time.timeScale` 设为 0，画面、物理、危险物全部静止。面板与快捷键照常可用（整个 Mod 都走非缩放时间）。仅离线 / 本地派对生效。
- **冻结角色** —— 只冻住自己的角色（速度清零、动画定格，并同步给其他玩家），其他人照常移动。不要与 EX 模块的同名开关同时打开。
- 两项在**每次启动时强制关闭**：绝不能让配置里残留的定格状态卡住下次启动。游戏没有原生网络消息能把未装 Mod 的房客写成 0 倍速，所以不提供联机定格。音频（Wwise）不受 `timeScale` 驱动，梦境期间声音会继续播放。

### 混乱牌组 Chaos Deck

把本来「一整局固定」的对局规则，改成每回合抽一张牌。第 3 回合突然全员低重力、第 5 回合镜像操作 —— 一局自己长出新剧本。

**2.0 起只需房主安装。** 抽牌发的是**真实的游戏规则消息**（`MsgGameRuleSet` + 真实 `TabletRule` / `Value`），由游戏自己的 `TabletRulesScreen` 在非房主端写进 `Modifiers`，所以没装 mod 的房客也会一起变，并能在原生规则界面看到当回合改了什么。房主端被游戏的 `!IsHost` 守卫挡住，因此本地双写一次。

- **房主单一随机源**：只有房主（或离线本机）抽牌，广播的是「抽到的结果」而不是种子，房客完全不随机，天然不会不同步。
- **10 张牌**：低重力 / 高重力 / 弱跳跃 / 慢冲刺 / 慢平台 / 禁用墙跳 / 镜像操作 / 跳舞无敌 / 玩家互撞 / 无摩擦，每张都能在牌池里单独关掉。射速、游戏速度、体型、相机翻转、末日刻意不收录：前两者会改写 `Time.timeScale`（与「时间控制」冲突），后三者碰相机或要重建绘制对象。
- **可调项**：每几回合抽一次、最多同时生效几张、抽牌提示、手动重抽快捷键；页面实时显示当前牌面。
- **随时可退回**：开局快照原规则值；关闭开关 / 对局结束时既重发每条规则的树屋原值（让未装 mod 的房客还原），也本地还原房主那份，并通知装了 mod 的房客清掉牌面标记。
- **房内 mod 清单**：复用同一条规则消息做周期握手，面板显示房间里哪些玩家装了本 mod。客户端收到的所有消息都来自服务器连接，因此握手用「本机玩家号」而不是 `conn.connectionId` 区分发件人。
- **房客提案（2.1）**：房客按提案键发一条「我建议这张牌」，走同一条 `None` + 魔数通道，只有房主处理；房主在本页看到待审卡片，可一键采纳或忽略，默认 20 秒过期（「可读性」页可加秒，过期后还能在通知历史里重新打开）。采纳后仍走真实规则广播，所以未装 mod 的房客一样会变。离线本机即房主，请直接用重抽键。
- 只用游戏已有的规则与消息类型：**不新增 Harmony 补丁、不新增 msgType、不新增反射登记、不改相机、不生成实体、不加线程**。

### 死亡鉴定书 Death Report

一局结束给一张「怎么死的」回顾卡片。纯本地：不联网、不加补丁、不加反射登记、不持任何游戏对象。

- 监听游戏自己的 `PlayerKilledEvent`（`setupDeath` 里 `base.hasAuthority` 时才发，所以只记本机角色的死亡）、`PiecePlacedEvent`、`NewMatchEvent`、`GameEndEvent`。
- 报告内容：总阵亡 / 回合数、主要死因 Top 3（中文名 + 次数）、首次阵亡回合、自己坑自己次数、最常坑你的人和一句评语。
- **「疑似元凶」是推断，不是精确归因**：游戏的 `PlayerKilledEvent` 只带 `Cause` 和 victim，不带 `causedByPlayerNumber`；那个参数只在 `setupDeath` 内部用于给凶手加分，联机时还走网络消息、不落本地列表。本功能按死因匹配本局最近一次放置的同名方块（`Placeable.KillType` / `Name` / `placedByPlayerNumber` 都是 public），同类方块有多块时可能认错，所以界面明确写「疑似」，也可以整个关掉。
- 联机时补听 `PiecePlaced` 网络消息统计别人的放置（本地 `PiecePlacedEvent` 只在放置者本机触发）。
- 局末自动在局内简报里弹卡片（默认 25 秒，可关），设置页保留上一局全文并可一键复制到剪贴板。
- 所有数据都是值（string / int / float），有上限（256 条死亡、512 条放置），换局自动清空 —— 游戏销毁方块不派事件，持引用必然读到回池对象。

### 局内简报 Match Brief

把上面三个新功能的状态汇总到**对局画面**里的一条可折叠小浮层（不打开设置面板也能看见）：

- 时间控制状态（梦境 / 冻结角色）、当前混乱牌面、派对盒最稀有道具、房内 mod 清单（可选）。**没有任何内容时整块不画**。
- **房客提案会强制展开浮层**并弹出黄色待审卡片（含倒计时）与「采纳 / 忽略」按钮 —— 这是这个功能真正被点到的地方，藏在设置页里 20 秒就过期了；现在过期也能从通知历史里补点。
- 四角停靠 + 拖动标题栏自定义位置、透明度 / 缩放 / 折叠快捷键；位置持久化。
- 浮层是自建的常驻 `MonoBehaviour.OnGUI`：核心的 `RegisterOverlay` 只在面板打开时派发（`DrawGUI` 在面板关闭时早退），做不了局内常驻。
- 状态一律走契约层 **Slots 槽位**（名字 + BCL 委托）：拆分构建下每个功能是独立 DLL，直接引用其它功能的类型会编译失败。删掉某个功能只会让对应那一行消失。
- 按钮点击不在 `OnGUI` 里直接发网络消息，只置一个带帧号的意图，由 Tick 执行一次，避开 IMGUI 一帧多趟重复触发。

### 品质光芒 Rarity Glow

按**当前概率**给派对盒里的道具加一圈品质光晕：概率越低越稀有、光越亮（可在页里反向）。

- 概率口径与派对盒自己的抽取逻辑同源：`BlockGroup.GetItemFilterWeight`（自动处理 `FilterOverride`），退化路径走 `GameSettings.GetBlockFrequency` + `TabletBlockList.GetWeightFromStepValue`。**不是**道具的基础稀有度。
- 6 档品质：泛滥 / 普通 / 精良 / 稀有 / 史诗 / 传说；权重为 0（本局不会出现）的道具不发光。强度、尺寸、呼吸脉动、反向着色、图例均可调。
- 实现方式：光晕是**道具自己的子对象**（程序生成径向渐变贴图，整局只建一次），排在道具本体后面、同排序层、同为 UI layer 5。用 `Transform.Find` 判重与更新，**完全无状态**——道具消失时光晕自动带走，不建强引用字典。
- 纯本地视觉：概率本来就是同步的，各端各算各画；不碰网络、不改原材质 / SpriteRenderer、不影响抽取结果、不新增补丁 / 反射 / 线程。
- 页面实时显示派对盒里各品质的件数（0.2 秒节流，走核心的按帧对象缓存）。

### 关卡记录 Level Recorder

按时间线**完整记录一局里发生的事**，并和布局预设双向联动。三页：时间线 / 布局快照 / 记录设置。

- 记录开局、阶段、放置、移除、得分、聊天、混乱牌面、布局预设载入、快照、离房、局末。服务器把放置 / 得分 / 聊天 / 到达消息转发给所有客户端，所以**只房主安装就能记录全场**；房客零安装，屏幕上看不到本页。
- 查看刻意不做长滚动：**按类型 / 回合 / 玩家 / 文字筛选 + 分页 + 点击展开详情**，一屏看完一页；一键复制筛选结果 / 整局、导出到 `BepInEx\config\SR_UCH\records\`。局末自动归档上一局，换局后仍可回看。
- **联动布局预设**：每回合自动抓一份关卡快照（沿用 `QuickSaver.GetCurrentXmlSnapshot`），每份都能一键存成布局预设；也能列出已有预设并直接载入。布局预设发起载入时，时间线自动记一条。
- 死亡记录只覆盖本机角色（游戏只在 `hasAuthority` 时派发 `PlayerKilledEvent`），页面与导出文本都写明这条限制，不冒充全场死亡。全部数据都是值，不持 Unity 对象；时间用 `unscaledTime`，梦境定格时照常记录。

### 开局档案 Match Profile

把「游戏原生规则 + 本 mod 配置」打包成一份房间设置，开房一键复原。

- 规则部分走游戏原生 `MsgApplyRuleset` 广播（`:46530` / `:111651`），**房客零安装也生效**；mod 配置只恢复房主本机。窗口尺寸、侧栏宽度与内部状态键不写入 / 不覆盖，与「重置默认」的约定一致。
- 档案文本一行一字段，XML 与配置快照用 Base64 承载，可复制给朋友或从剪贴板导入；导入拒绝 `DOCTYPE`，长度有上限。
- **套用前差异预览**：第一次点「套用」只列出这次会改哪些规则字段（与当前游戏生成的 XML 逐项对比）；游戏更新后改名 / 消失的字段会标 ⚠，只警告不阻断，旧档案仍可用。聊天指令 / 剪贴板导入跳过确认，但同样的差异会写进日志。
- **自检握手**：套用后自动重跑一次完整自检（补丁目标 / 反射成员 / 归因表），结论写进状态栏，也有手动「重扫自检」按钮。规则广播异常或重扫出错时，把本机 mod 配置回滚到套用前快照；「无联机房间」是已知边界，不算失败。
- 建议在**树屋 / 开局前**套用：规则应用逻辑挂在 `TabletRulesScreen` 上，对局中该界面是否仍在未实机确认。离线且没有联机连接时规则发不出去，只会恢复 mod 配置。

### 房主运维台 Host Console

一页看全房间状态（连接数 / 本机玩家号 / Ping / 平均 Ping / 场景 / 模式 / 回合）与五个功能的状态，一键复制整份报告并写入日志。

- **聊天指令**：房客用游戏原生聊天窗发 `/sr help | ping | rules | cards | report | copy | profile <名字>`，房主端执行并回复到聊天窗（未装 mod 的房客也看得见）。这是「仅房主安装」下房客 → 房主唯一的通道。
- 只有 `profile` 会写状态，且仅房主本人可触发；1.5 秒限流。若游戏设置关了文字聊天，回复会被游戏拒掉，房主端仍有一条本地提示。
- 全部汇总都是只读；不新增补丁 / msgType / 反射登记 / 线程。

### 通知中心 Notification Hub

把散落在各处的**屏幕提示统一收口**。`Notify`、`NotifyT`、`NotifyTag` 与核心自己的提示全都汇到 `SR.Notify.cs` 的 `NotifyImpl`，所以只在核心留一个可选钩子就能覆盖全部来源，不用改任何调用点；没装这个功能时行为一字不变。

- **优先级分级**：要动手的（房客提案、失败、拒绝）> 一般反馈 > 纯确认；3 秒窗口内同来源同内容合并成一条 `×N`，不再互相顶掉。
- **对局中静默**：低 / 中优先级只进历史不弹屏，高优先级照常弹。「退回游戏原生提示」是零风险回退开关，打开后只记历史不改屏幕。
- **历史回看**：按级别 / 文字 / 是否可补点筛选 + 分页 + 点击展开完整内容 + 复制 / 导出到 `BepInEx\config\SR_UCH\notices.txt` + 一键清空。
- **过期提案可补点**：混乱牌组里 20 秒没处理的提案，仍能在历史里点「重新打开」恢复待审。中 / 高优先级提示还会写进关卡记录器的时间线。
- 局内浮层是自建常驻 `MonoBehaviour.OnGUI`：优先级色条 + 长短编码 + 逐渐缩短的剩余时间条，一眼看出还来不来得及点。

### 可读性 Readability

拆掉这个 Mod 自己造出来的两道门槛：**全靠颜色分档**、**一闪而过的倒计时**。

- 品质光晕改用 **6 种形状图案**（虚点环 / 单环 / 双环 / 斜纹 / 棋盘 / 放射），图例同时给文字等级名与 `[n/6]` 序号 —— 颜色不再是唯一通道。
- **字号倍率**（80-160%）与**高对比**作用于局内简报和通知浮层；高对比还会给图例色块加描边。
- **额外加秒**（0-20）同时延长房客提案等待时间与通知停留时间，反应慢的人不再永远点不到。
- 四项都是**软适配**（经契约层 Slots 暴露）：删掉本功能只会让其它功能回到默认值，不报错也不少一行。不读取游戏字体资源，不新增补丁 / msgType / 反射登记 / 线程。

### 对局播报 Match Cast

把原先**只有房主屏幕上看得见**的状态，发到每个房客都有的**游戏原生聊天窗**，房客零安装也能看见。

- `ChatDisplay.NewChatMessage` 经 `NetMsgTypes.ChatSent` 发送，服务器用 `NetworkServer.SendToAll` 转发（`:84077` / `:39125`）。零新 msgType、补丁、反射登记、线程。
- 开局公布本局启用的混乱牌池（可选附本盒最稀有道具）；混乱牌组是**逐回合随机抽牌**，没有固定牌序可预告，所以每回合再播真正抽到的那张。局末把死亡鉴定书压成一行发战报。
- 限流复用通知中心的 3 秒同类合并与优先级分级，再加最小间隔、每回合上限、单条字数上限；删掉通知中心只是退回固定优先级。
- 游戏设置关了文字聊天（`EmotesOnly` / `ChatAndEmotesOff`）或离线时，降级成房主本机一条提示，不重试不刷屏。
- 只发文本，不改任何规则、分数或实体。

### 玩家轨迹 Player Tracker

- **移动轨迹**：在画面上绘制其他玩家最近的移动路径。
- 可调：轨迹长度、采样间隔、起点/终点线宽、瞬移判定距离、透明度。
- **默认关闭**；仅显示，不影响游戏判定。

### 方块破坏 Destroy Blocks

- 按 `Alt` 进入删除模式，滚轮切换目标，`Backspace` 删除。
- 删除时会显示**是谁放的**这个方块，可以追踪某个玩家。
- 另有列表模式：直接列出场上所有方块，刷新后点选。
- **破坏动画**开关会真正传给游戏的 `DestroySelf(..., useSmoke, ...)`：关掉后方块直接消失、不播烟雾。

### 会话 Chat

**对话窗口**页

- 按住 `Z` 显示聊天窗口，或按一下切成常驻（可改键）。
- 窗口缩放 `X` + 滚轮，文字大小 `C` + 滚轮。
- 可以关掉自动弹出、关掉淡入淡出、开启清晰度、调整窗口位置。
- 把「启用增强」关掉，游戏原本的字号 / 缩放 / 位置会**还原一次**后完全交回原版。

**对话内容**页

- 会话内的聊天记录面板，可以记录和发送。
- **发送走的是游戏自己的聊天通道**（`ChatSystem`，与游戏内聊天一致，房主/房客都能看到），不是本地只读。
- 记录、过滤、隐藏游戏聊天窗口、显示时间这些**只影响本机显示**，不会改动别人看到的内容。

### 快速调整 Quick Adjust

- **分数折扣** —— 把自己的 handicap 设成 100 减折扣，这一局立刻生效，平衡板上能看到；可一键恢复原值。
- **快速切换** —— 长按 `B` 在行动 ↔ 建造之间来回切。
- **挑战**（第 2 页）—— 死后自动重试 / 长按快速重试 + 等待秒数；挑战模式里死了自动重来。

### 角色 Character

- **自动选择** —— 进入树屋/房间时自动挑一次角色：指定角色 / 随机空闲 / 智能（按存档统计挑最常用的）；只处理已解锁的角色，已有角色不动。
- **自动时装** —— 角色选定后自动随机穿一套外观（只用已解锁的外观），也可以手动「随机整套」。

### 重生 Respawn（在「快速调整 → 重生」页）

- **重生延迟** —— 死亡后等多少秒再自动重生（挑战 / 自由通用，默认 0.5 秒，游戏原生长按阈值）。
- **出生无敌** —— 每次出生后的无敌秒数（默认 1 秒，游戏原生重生后就是 1 秒）。
- **炮弹卡死重生** —— 死了还卡在炮弹里超过 1.5 秒自动重生。
- **死亡无计分板** —— 挑战模式死亡时不弹记分板（只在死亡且尚未通关时生效）。

### 布局预设 Layout Presets

- 把当前方块布局保存为命名预设，之后一键加载（加载仅房主可用）。
- 预设存放在 `BepInEx/config/SR_UCH/presets/`；支持导出到剪贴板 / 从剪贴板导入，方便分享。
- 加载会走原生重载：分数是否保留取决于“重载关卡”的模式设置。

### HUD

- 屏幕小窗显示当前阶段、阶段倒计时与回合进度。
- 倒计时最后 10 秒变黄、最后 5 秒变红；可选闪烁与阶段切换提示。
- 纯本地：不发送任何网络消息，不影响游戏判定。可拖动；**拖动后的位置只在本次会话有效，不写配置**（下次启动回到默认位置）。
- 显示方式默认 **切换**：开局 HUD 就在，按键只负责隐藏/显示。
- 配置段原名「Round HUD」，升级后会自动迁移到 `[HUD]`，所有取值保留。
